# 💻 Projetos Web - Desenvolvimento Front-end

Este repositório reúne três aplicações desenvolvidas como prática de desenvolvimento web, com foco em estruturação de interfaces, estilização e interatividade utilizando JavaScript.

---

## 📂 Estrutura do Repositório

├── evento
├── portfolio  
└── restaurante  

Cada pasta representa um projeto independente.

---

## 🚀 Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- Manipulação de DOM
- Versionamento com Git

---

## 📌 Projetos

### 🔹 Evento de Tecnologia
Landing page desenvolvida para divulgação de um evento fictício da área de tecnologia, com foco em organização de informações, layout moderno e navegação intuitiva.

### 🔹 Portfólio Pessoal
Página de apresentação profissional com seções organizadas para exibição de habilidades, projetos e informações de contato.

### 🔹 Sistema Web para Restaurante
Aplicação com cardápio interativo e cálculo automático de pedidos utilizando JavaScript para manipulação dinâmica de elementos.

---

## 🎯 Objetivo

Consolidar conhecimentos em desenvolvimento front-end por meio da criação de aplicações completas e estruturadas.
